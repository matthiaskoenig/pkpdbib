# Release notes for pkpdbib 0.2.2
![pkpdbib](./docs/images/favicon/pkpdbib-100x100-300dpi.png)

## Security

- The emSign root CA with compromised intermediate keys is no longer trusted: `pkpdbib` requires `certifi>=2026.10.19` ([GHSA-6q48-6c7w-9gw2](https://github.com/advisories/GHSA-6q48-6c7w-9gw2)), the certificate authorities requests (a dependency of `scidownl`) uses, and continuous integration and the release build run uv 0.13.4 ([GHSA-hq85-5cpj-mr62](https://github.com/advisories/GHSA-hq85-5cpj-mr62)), whose bundled CA store has the same fix.

## Other changes

- Lighter continuous integration (python 3.14 on linux, macos and windows, superseded runs cancelled, monthly dependabot) and updated locked dependencies, actions and hooks.
