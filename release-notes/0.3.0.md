# Release notes for pkpdbib 0.3.0
![pkpdbib](./docs/images/favicon/pkpdbib-100x100-300dpi.png)

## Breaking changes

- The code is now licensed under the [MIT license](https://opensource.org/license/MIT) instead of the LGPLv3, as the other packages of the group (sbmlutils, sbmlsim, pymetadata).
- `pyzotero` and `polars` are standard dependencies, the optional `zotero` extra was removed; `pip install pkpdbib` installs everything needed for `pkpdbib.zotero_tools`.

## Documentation

- The README is a short entry point, the details (usage, citation, funding) are in the [documentation](https://matthiaskoenig.github.io/pkpdbib).
